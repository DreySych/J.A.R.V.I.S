## Модуль камеры

Модуль `vision/camera.py` работает на Raspberry Pi.

- Делает зеркальные фотографии в JPG и записывает зеркальное MP4-видео со звуком с микрофона INMP441.
- Включает внешний светодиод на GPIO17 на время записи видео.
- Сохраняет файлы на Raspberry Pi, а их имена, типы и даты сохранения — в SQLite.
- Позволяет получать, удалять и просматривать список сохранённого контента.
- При запуске отправляет описание и список инструментов центральному модулю, если указан адрес регистрации.

### Установка и запуск

На Raspberry Pi установите зависимости:

```bash
sudo apt update
sudo apt install python3-flask python3-picamera2 python3-gpiozero python3-lgpio ffmpeg alsa-utils
```

Из корневой папки проекта запустите сервер:

```bash
python3 vision/camera.py
```

Сервер принимает запросы на порту `5000`. Для остановки нажмите `Ctrl+C` в терминале запуска.

Для записи звука микрофон должен быть настроен в системе. Текущий код использует ALSA-устройство `plughw:CARD=sndrpigooglevoi,DEV=0`. Проверить список устройств записи можно командой:

```bash
arecord -l
```

### Эндпоинты

Параметры передаются в JSON body. Поле `type` принимает `photo` или `video`.

| Метод и путь | Входные параметры | Результат |
| --- | --- | --- |
| `POST /capture_photo/` | `name` — необязательное имя | Делает фото. Возвращает `result: success` и имя сохранённого снимка. |
| `POST /start_video/` | Без параметров | Начинает запись видео и включает светодиод. Возвращает `result: success` и `status: recording`. |
| `GET /video_status/` | Без параметров | Возвращает статус `recording` или `stopped`. |
| `POST /stop_video/` | `name` — необязательное имя | Останавливает запись, выключает светодиод и сохраняет MP4. Возвращает `result: success` и имя видео. |
| `POST /get_media/` | Обязательные `type` и `name` | Возвращает файл JPG или MP4. |
| `DELETE /delete_media/` | Обязательный `type`, необязательный `name` | Удаляет файл и запись в БД. Без имени удаляет последний сохранённый файл указанного типа. Возвращает `result: success`. |
| `GET /list_media/` | Без параметров | Возвращает обычный текст с именами, типами и датами сохранения. Последние записи идут первыми. |
| `GET /module_info/` | Без параметров | Возвращает JSON с идентификатором, описанием, адресом камеры и списком инструментов. |

### Имена и хранение

Без имени камера назначает его автоматически — `photo1`, `photo2`, `video1` и так далее.

Повтор имени внутри одного типа возвращает HTTP `409`. Фото и видео могут иметь одинаковое имя. Если файл для получения или удаления не найден, сервер возвращает HTTP `404`.

Файлы находятся в папке `vision/media/`, сведения о них — в `vision/database.db`.

### Регистрация в J.A.R.V.I.S.

В переменной `CENTRAL_REGISTRATION_URL` файла `vision/camera.py` указывается полный адрес обработчика регистрации центрального мозга, включая протокол, IP, порт и путь.

После запуска сервера камера отправляет на этот адрес POST-запрос с описанием модуля `camera-01` и списком инструментов. Адрес самой камеры определяется автоматически по сетевому маршруту к мозгу.

Результат отправки выводится в терминале. При ошибке выполняется до трёх попыток. Если адрес регистрации пустой или отправка не удалась, сервер камеры продолжает работать.

Отправка регистрации выполняется при каждом запуске программы. Для запуска при включении Raspberry Pi нужно отдельно настроить службу systemd.
